# 01 需求与场景

## 背景

基于移动云 MoMA 平台，面向“高效办成一件事”政务场景，构建多 Agent 智能体应用，帮助群众“一次申请、并联办理、一次出件”。

## 两个场景（共用一套框架）

### 开办企业一件事
- 事项：企业设立登记、税务登记、社保登记、公章刻制、银行开户（可选）。
- 用户：创业者、中小企业主。

### 开办餐饮店一件事
- 事项：个体工商户设立登记、食品经营许可证、健康证、消防安全检查（条件触发）、户外招牌（条件触发）。
- 用户：个体经营者、小微商户（数量远大于企业，更贴近日常）。

## 用户与痛点

- 不清楚“先办什么、后办什么、哪些能并行”。
- 材料反复提交、多部门来回跑。
- 不同经营条件（面积、油烟、生食）导致所需事项不同，群众难以自行判断。

## 价值

- 一个入口、一次填写、并联办理，降低办事门槛。
- 用 MoMA 的多模型调度、智能路由、上下文管理承载“条件判定 + 并联流转”的复杂逻辑。

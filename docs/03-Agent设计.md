# 03 Agent 设计

## Agent 划分与职责

| Agent | 职责 | 输入 -> 输出 | 触发 |
| --- | --- | --- | --- |
| 主 Agent | 意图识别、任务拆解、全局上下文、汇总结果 | 自然语言 -> 办理单 | 始终在线 |
| 咨询 Agent | 解答流程与材料问题 | 问题 -> 办理要点 | 咨询意图 |
| 信息采集 Agent | 多轮采集信息、生成结构化表单 | 对话 -> 表单 | 开始办事 |
| 条件判定 Agent | 按条件判定事项与材料（智能路由核心） | 表单 -> 事项+材料清单 | 表单完成后 |
| 材料核验 Agent | 校验材料是否齐全、合规 | 材料 -> 核验报告 | 提交材料 |
| 部门事项 Agent | 办理单个并联事项，办结后回调主 Agent 打勾流程节点 | 事项 -> 办理结果 | 并联提交后（按事项动态创建） |
| 进度跟踪 Agent | 查询办理流程节点与并联办理进度 | 办理单 -> 进度看板 | 查询意图 |

## 条件路由规则（餐饮店示例）

| 条件 | 判定 | 路由结果 |
| --- | --- | --- |
| 经营类型 = 热食/有油烟 | 需油烟净化 | 增加材料：油烟净化设施证明 |
| 面积 >= 300 ㎡ | 需消防检查 | 增加事项：消防安全检查 |
| 经营生食/冷食 | 需专间 | 增加材料：专间布局图 |
| 设置户外招牌 | 需审批 | 增加事项：招牌设施设置 |

规则采用“规则引擎/小模型”判定，快且可控；判定结果写入全局上下文，供后续 Agent 使用。

# 02 总体架构

```
+-------------------------------------------------------------+
|  接入层   PySide6 桌面客户端（聊天 / 表单 / 进度看板）         |
+-------------------------------------------------------------+
|  编排层   MoMA 多 Agent 编排（主 Agent + 子 Agent 群）        |
|           任务规划 · 智能路由 · 上下文传递 · 工具调用          |
+-------------------------------------------------------------+
|  能力层   MoMA：多模型调度 / 智能路由 / 上下文管理             |
|           RAG 检索 · Function Calling · 工作流引擎            |
+-------------------------------------------------------------+
|  模型层   九天大模型 + 生态模型（DeepSeek / Qwen / GLM 等）    |
+-------------------------------------------------------------+
|  数据层   政策知识库 · 办事指南 · 材料模板 · 用户档案 · 会话   |
+-------------------------------------------------------------+
|  集成层   政务系统对接（模拟）：市场监管/税务/消防/城管/卫健    |
+-------------------------------------------------------------+
|  安全层   RBAC · 数据脱敏 · 审计日志 · 备案合规                |
+-------------------------------------------------------------+
```

## 关键设计

- **场景化配置**：企业与餐饮店共用编排框架，差异全部放在 `scenarios/*.json`（事项、字段、条件规则）。
- **主 Agent 编排**：意图识别 -> 咨询 -> 信息采集 -> 条件判定 -> 材料核验 -> 并联提交 -> 各部门事项办理 -> 进度查询。每个节点完成即“打勾”，形成可查询的办理流程进度；部门事项子 Agent 办结后回调主 Agent 更新节点（见 `docs/06`）。
- **MoMA 三能力落点**：
  - 多模型调度：咨询用强模型、采集用轻量模型、核验用多模态模型、判定/进度用规则引擎。
  - 智能路由：意图路由到子 Agent；条件判定路由到不同事项与材料。
  - 上下文管理：全局会话上下文在多个 Agent 间共享，避免重复询问。

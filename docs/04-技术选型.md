# 04 技术选型

| 层级 | 选型 | 理由 |
| --- | --- | --- |
| 平台底座 | 移动云 MoMA | 赛题指定，原生多模型调度/智能路由/上下文管理 |
| 主力模型 | 九天大模型 + DeepSeek / Qwen / GLM | 九天契合主办方，生态模型补推理与成本 |
| 多模态 | Qwen-VL 等 | 证件识别（材料核验） |
| 编排 | MoMA 原生 Agent + 轻量编排层 | 突出 MoMA，兼顾工程可控 |
| 知识库 | 向量库 + Embedding（BGE 等） | 政策问答与条款检索 |
| 上下文 | Redis（短期会话）+ 数据库（长期档案） | 多轮与跨会话记忆 |
| 结构化数据 | PostgreSQL / MySQL | 表单、档案、办理状态 |
| 前端 | Vue 3 + TypeScript（Vite + Pinia） | 既能做网页、也为兼容 APP 预留，组件化契合聊天 / 表单 / 看板 |
| 后端 | Python / FastAPI | 与 MoMA API 对接、编排 Agent，并以 SSE 向前端推送进度 |

> 骨架阶段为“零依赖”可运行：核心模型用 dataclass，Mock 政务接口与 MoMA 客户端均为桩实现。
